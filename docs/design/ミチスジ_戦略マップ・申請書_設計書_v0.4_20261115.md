## 0. この版で変えたこと（v0.3から）

| 論点 | v0.3 | v0.4 |
|---|---|---|
| DXの段階の扱い | 事業ごとに7項目の状況を自己申告し、3段階にまとめて「到達段階」を出す。全社のゴールのラインも段階で置く | **段階そのものは評価の軸にしない。** 段階は施策に付けたIPAの項目から自動で決まり、「その段階の施策から、道筋がどこまで進んだか」を見る |

| 組込みチェック | ①目標と役割の合意、②実行条件、③検証と次の判断 | **①をなくす。** 事業部・経営が先に決め、DX推進部が加わって作るので、出した時点で合意は済んでいる。②③は「実行の準備」として施策の詳細に残す |
| チップの表示 | IPA項目の番号と、①②③の3つの点 | 3つの点をなくす。番号の色で段階（デジタイゼーション／デジタライゼーション／DX）を示す |
| マップの切り替え | 見る人（全体／事業部／DX推進部） | **「DXの段階で見る」を追加。** その段階の施策と、そこから財務までの道筋を強調する |
| 比較の画面 | 散布図。横＝到達段階、縦＝①合意がある施策の割合。全社の値は売上比率で加重平均 | **マス目。横＝道筋の進み（4視点）、縦＝DXの3段階、点＝事業。** 合意の割合と売上加重はなくす |
| 経産省の画面 | 合意の割合、DX段階の事業の割合 | 同じマス目で、参加企業の全事業の分布を出す |
| 制度の言い方 | 制度（インセンティブ）の運用に使う | お金は出さない。**経産省による評価・表彰の基準を、この道筋の上で示す**（9章） |

変えていないこと：
- 対象は従業員1,000人以上で、DX推進部のある上場企業
- 骨格はBSCの戦略マップ。列は4視点、行は全社の帯と事業の帯、施策は目標に付くチップ
- 起点は事業の目標。申請書は事業の方向（第1層）を先に聞く
- 足りないところ（財務につながっていない目標、施策がない目標、どこにも付いていない施策）を赤の点線で出す
- 更新は半年〜1年ごと。評価・報酬の変更は条件にしない
- 経産省は個別のKPIや評価制度を勧めない（11/11 経産省ヒアリング）

## 2. 骨格と物差し

### 2-1 骨格：BSCの戦略マップ

- **4つの視点**と因果のつながり：学習と成長 → 業務プロセス → 顧客 → 財務。左ほど先行指標、右ほど遅行指標（Kaplan & Norton「Having Trouble with Your Strategy? Then Map It」HBR 2000年9–10月号 → [原文PDF](https://fenix.iseg.ulisboa.pt/downloadFile/281608120752633/Kaplan%20Norton%20(2000).pdf)）
- **各視点の中身**（Kaplan & Norton『戦略マップ』2004。[noteの要約](https://note.com/zum_ism/n/nf9895177fd81)で確認。原典は未確認）
  - 学習と成長：人的資本・情報資本・組織資本
  - 業務プロセス：業務管理・顧客管理・イノベーション・規制と社会
  - 顧客：顧客の成果（満足・維持・獲得・収益性・シェア）と、その土台の顧客価値提案
  - 財務：収益増大と生産性向上の2本柱
- **価値提案の四類型**：トータル・コスト・リーダーシップ／製品リーダーシップ／完全な顧客ソリューション／システムロックインから1つ選ぶ（同上）
- **時間軸の目安**：短期（0〜1年）＝業務管理、中期（1〜3年）＝顧客管理、長期（3〜4年）＝製品開発力・技術提携・地域社会（同上）
- **複数事業**：全社 → 事業部 → 支援部門の順に優先事項をそろえる（Kaplan & Norton『Alignment』2006。[HBS Working Knowledge の著者抜粋](https://www.library.hbs.edu/working-knowledge/managing-alignment-as-a-process)）。事業部の指標は、全社の指標と同じでなくてよい（[HBS Working Knowledge「Partnering and the Balanced Scorecard」](https://www.library.hbs.edu/working-knowledge/partnering-and-the-balanced-scorecard)）

### 2-2 DXの段階：IPAの3段階・7項目

| 段階 | 取組項目 |
|---|---|
| デジタイゼーション | 1. アナログ・物理データのデジタル化 |
| デジタライゼーション | 2. 業務の効率化による生産性の向上／3. 既存製品・サービスの高付加価値化 |
| デジタルトランスフォーメーション | 4. 新規製品・サービスの創出／5. 組織横断／全体の業務・製造プロセスのデジタル化／6. 顧客起点の価値創出によるビジネスモデルの根本的な変革／7. 企業文化や組織マインドの根本的な変革 |

（分類の対応を確認した出典：[IPA『DX動向2025』本文 p.16 図表1-19](https://www.ipa.go.jp/digital/chousa/dx-trend/tbl5kb0000001mn2-att/dx-trend-2025.pdf)。項目番号は分類を表し、項目1から7までを順番に達成する進捗段階としては扱わない）

**v0.4での使い方**：7項目は別の物差しとして外に置かず、戦略マップの中に埋め込む。
- デジタルの施策に、7項目のどれにあたるかのタグを付ける（企業が選ぶ）
- 段階はタグから決まる（1＝デジタイゼーション、2・3＝デジタライゼーション、4〜7＝DX）
- **「自動」の意味**：企業が施策に付けたIPA項目を、上の対応表に従って段階表示に変換する。施策の文章をAIなどが読み取って分類する機能ではない。例えば、項目3を選んだ施策には「デジタライゼーション」と表示する
- 段階の表示と「道筋の進み」は別の計算。指標の変化は道筋の進みの判定に使い、施策の段階の分類には使わない
- 評価するのは「その段階に着いたこと」ではなく、「その段階の施策から、道筋がどこまで進んだか」

### 2-3 チーム独自の部分

次の4つは研究で確立したルールではなく、**チームの設計案**。
- 4視点を左から右に寝かせ、施策をチップにした画面の形
- 道筋の進みの判定（6章）
- 7項目ごとの状況を別途自己申告させず、企業が選ぶ施策のタグから段階を、指標の動きから道筋の進みを出すこと
- 比較画面のマス目（道筋の進み × DXの段階）

## 3. データ構造

```
会社
 ├ 全社の目標（財務・中期経営計画）
 ├ 事業（1〜n）
 │   ├ 事業の財務目標（収益増大分／生産性向上分）
 │   ├ 顧客価値提案（四類型から1つ）・顧客の成果目標
 │   ├ 戦略テーマ（1〜3）
 │   │   └ 目標（4視点のどれか）＋指標
 │   └ 目標どうしのつながり（矢印）
 ├ 施策（目標に付くチップ。1つの施策が複数の事業の目標に付いてよい）
 │   ├ IPAの項目（デジタルの施策の場合）
 │   └ 実行の準備（実行条件の確保／検証と次の判断日）
 └ 更新履歴（前の版を残す）
```

| データ | 主な項目 | 備考 |
|---|---|---|
| 会社 | 企業名、法人番号、業種、従業員規模、上場区分、売上規模 | 企業名・法人番号はDX認定・DX調査から読み込む |
| 全社の目標 | 指標、基準値、現在値、目標値、目標年度 | 中期経営計画の目標 |
| 事業 | 事業名、業種、全社売上に占める割合、事業の責任者、事業側で確認した人・日付 | 比較の点の単位。売上の割合は表示だけに使い、計算には使わない |
| 戦略テーマ | テーマ名、業務プロセスの分類（4つ）、時間軸（短期・中期・長期） | 事業ごとに1〜3個 |
| 目標 | 視点（学習と成長／業務プロセス／顧客／財務）、目標名、主担当（事業部／DX推進部／経営）、協働部門 | 学習と成長は資本の種類（人的・情報・組織）も持つ |
| 指標 | 指標名、定義、基準値・時点、現在値、目標値、期限、測り方 | 基準値は上書きしない |
| つながり | 元の目標 → 先の目標、理由（仮説）、成り立つ条件、次に確かめること・時期 | 同じ事業の中でつなぐ |
| 施策 | 施策名、付く目標（複数可）、主担当、協働、デジタルか、**IPAの項目**（デジタルの場合）、実行の状態（検討・試行・実行・中止）、検証の状態、施策の指標 | 情報資本の施策の指標は、開発状況・安定稼働・利用率を想定 |
| 実行の準備 | 実行条件（予算・工数・権限・データの提供者）の確保、検証と次の判断日の決定、決めた場（会議体・日付・資料） | 施策ごと。v0.3の組込みチェック②③ |

v0.3から外したデータ：組込みチェック①、IPA項目の状況（今・3年後の自己申告）、ゴールのライン。

## 4. 戦略マップ（主画面）

### 4-1 構成

| 要素 | 内容 |
|---|---|
| 列（左→右） | ①学習と成長（人・データ・組織の準備）→ ②業務プロセス → ③顧客 → ④財務。列の見出しに「先行 → 遅行」を添える |
| 全社の帯 | 全社の財務目標と、その進み（基準 → 今 → 目標の何%まで来たか）。事業をまたぐ施策（項目5）と、組織・文化の施策（項目7）の名前 |
| 事業の帯 | 帯は開閉でき、事業で絞り込める。帯の中に戦略テーマを1〜3段 |
| 帯の見出し | 事業名、売上の割合、顧客価値提案の類型、**道筋の進み**（例：顧客まで）、**道筋にあるDX**（例：デジタライゼーション（項目2・3）／DX（項目5））、責任者、事業側の確認 |
| 右の詳細パネル | 選んだ目標・施策・テーマ・事業の中身 |

### 4-2 箱（目標）とチップ（施策）

- **箱＝目標**：目標名、指標（基準 → 現在 → 目標、期限）、主担当（色）、協働（文字）。指標がない場合は点線
- **チップ＝施策**：目標の箱の下に付ける。表示するのは、IPA項目の番号（色で段階を示す）または「非デジ」、施策名、「共通」の印（複数の事業に付く場合）、実行の状態
- チップの番号の色：デジタイゼーション（項目1）＝薄い水色、デジタライゼーション（項目2・3）＝青、DX（項目4〜7）＝濃い青。色だけで伝えず、番号・凡例・詳細パネルに段階の名前を出す
- チップを押すと、右のパネルに施策の中身（DXの段階、この先の道筋がどこまで進んだか、実行・検証の状態、施策の指標、実行の準備）を出す

### 4-3 矢印と強調

- 矢印は目標から目標へ引く（施策から直接は引かない）
- **箱を押す**と、その目標の前後と、財務までの道筋を強調する
- **チップを押す**と、その施策が付いた目標から財務までの道筋を強調する
- **「DXの段階で見る」**（すべて／デジタイゼーション／デジタライゼーション／DX）を選ぶと、その段階の施策と、そこから財務までの道筋を強調する
- 「見る人」（全体／事業部／DX推進部）を選ぶと、その部門が主担当の箱・チップと、その先の道筋を強調する

### 4-4 足りないところを目立たせる（赤の点線）

1. **財務につながっていない目標**：右へ向かう矢印をたどっても、財務の目標に届かない
2. **施策が付いていない目標**：その目標にも、左側でつながる目標にも施策がない
3. **事業の目標に付いていない施策**：どの目標にも付いていない（専用の欄に出す）

### 4-5 時点の切り替え

- 前回の更新時点と現在を切り替える
- 何をして、何が変わったかを一覧で出す（道筋の進みがどこからどこへ伸びたかを含む）

## 5. 申請書（入力）

### 5-1 全体の流れ

| 区分 | ステップ | ここで決めること | 主に話す人 |
|---|---|---|---|
| 準備 | 0. 会社と事業 | 対象にする事業 | 事業部・経営（入力はDX推進部が手伝ってよい） |
| 第1層（事業ごと） | 1. 財務の目標 | 事業の財務目標と今との差。差を収益増大分と生産性向上分に分ける | 事業部・経営 |
| | 2. 顧客への価値 | どの顧客に、どんな価値で選ばれるか（四類型から1つ） | 事業部・経営 |
| | 3. 戦略テーマと業務 | どの業務を変えるか（1〜3テーマ） | 事業部・経営 |
| 第2層（DX推進部が加わる） | 4. 必要な力と施策 | 人・データ・組織の何が足りないか。施策をどの目標に付けるか。デジタルの施策にはIPAの項目を付ける | 事業部＋DX推進部 |
| | 5. つながりと検証 | 矢印の理由、確かめること、時期 | 事業部＋DX推進部 |
| | 6. 実行の準備 | 施策ごとに、実行条件と、検証・次の判断日が決まっているか | 事業部＋DX推進部 |
| DXの段階 | 7. 道筋にあるDX（自動） | **このステップでの追加入力なし。** ステップ4で企業が選んだIPA項目に対応する段階と、指標の変化から計算した道筋の進みを確かめる | 全員 |
| 確認 | 8. 一枚で確認 | 読み合わせと、未決のことの一覧 | 全員 |

- 未決でも下書きで保存できる。数値を埋めないと進めない作りにはしない
- 既存の資料から読み込んだ項目は「既存資料から取り込み済み」と出す

### 5-2 入力項目（v0.3から変わったところ）

ステップ0〜5の項目は v0.3 の 5-2〜5-4（項目0-1〜5-1）と同じ。変えたのは次のとおり。

| No | 項目 | v0.4 |
|---|---|---|
| 0-4 | 対象にする事業（名前・業種・全社売上に占める割合・責任者） | 残す。売上の割合は表示だけに使う |
| 4-3 | デジタル施策か。デジタルならIPA項目（1〜7） | 残す。**DXの段階はこの項目から自動で決まる** |
| 6-1 | 組込みチェック①目標と役割の合意 | **なくす** |
| 6-2 | 実行条件（予算・工数・権限・データの提供者）の確保 | 「実行の準備」として残す |
| 6-3 | 検証と次の判断日 | 「実行の準備」として残す |
| 6-4 | 決めた場（会議体・日付・資料） | 残す |
| 6-5 | （任意）今の評価や業務量と、新しく求める行動がぶつかっていないか | 残す |
| 7-1〜7-3 | IPA 7項目の今と3年後、ゴールのライン | **なくす。** ステップ7は自動で出た結果を見るだけ |

実行条件の予算は、『戦略マップ』の「戦略投資は通常の設備投資・運営費とは別枠で確保する（STRATEX）」という考え方を参考にする（[noteの要約](https://note.com/zum_ism/n/nf9895177fd81)で確認）。

### 5-3 確認（ステップ8）

| No | 項目 | 内容 |
|---|---|---|
| 8-1 | 一枚で読み合わせ | 事業ごとに、財務 → 顧客 → 業務 → 学習と成長 → 施策を並べて表示 |
| 8-2 | 未決のことの一覧（自動） | 事業側の確認がない／財務につながっていない目標／施策が付いていない目標／どこにも付いていない施策／試行・実行中なのに実行条件が未確保の施策 |

### 5-4 定期更新（半年〜1年ごと）

| No | 項目 |
|---|---|
| U-1 | 各指標の現在値（基準値は上書きしない） |
| U-2 | 施策の実行・検証の状態、実行の準備の変化 |
| U-3 | 指標が動かなかった・下がったものの主な理由（選択：施策が遅れた／施策は進んだが指標が動かない／外部環境が変わった／測れていない／その他） |
| U-4 | つながり（仮説）を見直したか（見直して変えた／見直したが変えていない／見直していない）と、変えた内容 |
| U-5 | 施策・テーマ・目標の追加・中止（中止も履歴に残す） |

## 6. 判定のルール

表示は戦略マップに入れた内容から自動で出す。元になるIPA項目は企業が選び、指標値や施策の状態も企業が入力する。段階や道筋の進みを別途選んで申告するものではない。

| 表示 | 決め方 |
|---|---|
| 施策のDXの段階 | 施策に付けたIPAの項目で決まる（1＝デジタイゼーション、2・3＝デジタライゼーション、4〜7＝DX）。項目は、施策が何を変えるかで企業が選ぶ |
| 指標が動いた | 現在値が、基準値から目標値の方向へ動いている |
| **道筋の進み**（事業ごと） | 試行・実行中の施策が付いた目標から始めて、矢印を左から右へたどる。指標が動いた目標を順につないでいき、届いた一番右の視点（学習と成長／業務プロセス／顧客／財務）をその事業の進みとする。**途中の目標が動いていなければ、その先は数えない。** 施策と道筋でつながっていない指標が動いても数えない |
| 項目ごとの進み | 同じ計算を、その項目の施策だけを出発点にして行う（例：項目3の施策から、顧客まで進んだ） |
| **事業の段階**（比較の縦） | その事業の道筋にある、試行・実行中のデジタル施策のうち、一番上の段階 |
| 財務につながっていない目標 | その目標から矢印をたどって、財務の列の目標に届かない |
| 施策が付いていない目標 | その目標と、そこへつながる左側の目標のどれにも施策がない |
| どこにも付いていない施策 | 付く目標が「なし」 |
| 実績の読み方 | 基準値からの変化で見る。見るのは「施策を実行した道筋の上で、指標がどう動いたか」。道筋の外で売上だけが動いても、進みには数えない |

モックの架空企業での例：
- 産業機器事業：2026年3月末は「学習と成長まで」（稼働データの欠損なし率は動いたが、提案件数がまだ動いていなかった）。現在は提案件数 → 継続率 → 既存顧客の売上と順に動き、「財務まで」
- 計測機器事業：採用社数までは動いたが、新製品の売上はまだ0億円なので「顧客まで」
- 予防保守サービス事業（新規）：故障予知の精度は動いたが、その先の目標に指標がまだないので「学習と成長まで」

## 7. 他社と比べる（別画面）

### 7-1 マス目（道筋の進み × DXの段階）

| 要素 | 内容 |
|---|---|
| 点 | **事業ごとに1つ。** 自社の事業は色付き（現在は塗り、前回の更新時点は白抜き、点線で結ぶ）。右へ動いたことが進捗になる |
| 横（5つ） | 道筋の進み：まだ動いていない／学習と成長／業務プロセス／顧客／財務 |
| 縦（3つ） | 事業の段階：デジタイゼーション／デジタライゼーション／DX |
| 他社 | マスの濃さと数字で、比べる相手の事業がそのマスにいる割合を出す。個別の点や企業名は出さない |
| 比べる相手 | 同じ業種の事業／参加企業の全事業 |
| 出ない事業 | 試行・実行中のデジタル施策がない事業は、マス目には出さない（一覧には出す） |

読み方：段階が高くても、道筋を右へ進んでいなければ評価されない。段階そのものを評価の軸にしない、という考え方を1枚で見せる。

### 7-2 自社の事業の一覧

事業ごとに、道筋にあるDX（段階と項目）、道筋の進み（前回 → 現在）、4つの視点のどこまで進んだかの帯を出す。

### 7-3 項目ごとの比較（自社と、比べる相手の平均）

- 財務までつながっている目標の割合
- 実行条件の確保がある施策の割合
- 検証と次の判断日が決まっている施策の割合
- 検証が済んだ施策の割合（効果あり・なし）
- 指標の視点別の構成：学習と成長／業務プロセス／顧客／財務のそれぞれに何割の指標があるか

自社の値は単純な割合で出す。売上の割合での重み付けはしない。

### 7-4 道筋にあるDX（7項目の表）

行＝事業、列＝項目1〜7。その項目の施策がある事業について、その施策から道筋がどこまで進んだかを出す。施策がない項目は「—」。

### 7-5 出さないもの

- 順位
- 施策・目標の件数（会社ごとに切り分け方が違うため）
- 合意の割合、売上加重の全社の値（v0.3から外した）

## 8. 経産省の画面

- 参加企業数（事業数）、直近1年以内に更新した企業数
- 顧客・財務まで道筋が進んだ事業の割合、業務プロセスで止まっている事業の割合、どの目標にも付いていない施策の割合
- **参加企業の全事業のマス目**（7-1と同じ形）。どの段階の事業が、道筋のどこで止まっているかの分布
- 業種別：顧客・財務まで道筋が進んだ事業の割合
- 指標の視点別の構成（全体・業種別）：日本企業の成果指標の対象は「内向きの業務改革（社内の効率化）」が80.0%、「外向きの業務改革（新たなビジネスや顧客価値の創出）」が33.5%（[IPA『DX動向2026』p.19 図表2-15](https://www.ipa.go.jp/digital/chousa/dx-trend/)。手元：参考資料/dx-trend-2026.pdf）。この偏りが参加企業の中でどう変わるかを、定点で見られるようにする
- 企業一覧：企業名、業種、対象の事業数、道筋が一番進んだ事業（段階・進み）、最終更新

## 9. 評価・表彰とのつながり（チームの提言）

## 11. 未決事項

1. **事業の段階がDXの行に集まりやすい**：「一番上の段階」で決めると、DXの項目（4〜7）の施策が1つでもあればDXの行になる。モックの架空企業は3事業ともDXの行になった。他社との違いが横にしか出ない場合、縦の決め方（例：一番進んだ道筋にある施策の段階）を見直すか検討する
2. **「指標が動いた」の線引き**：今は基準値から少しでも目標の方向へ動けば「動いた」とする。誤差の範囲の動きをどう扱うか
3. **原典の確認**：『戦略マップ』（2004）の内容はnoteの要約で確認したもの。発表までに原典で確かめるか
4. **評価・表彰の基準の裏づけ**：9章の見立て（DX銘柄が点の評価で基準が見えにくい）を支える事実を、調査メモ29・30から整理する
5. **事業の業種の区分**：日本標準産業分類の大分類か、DX推進指標のベンチマークの区分か
6. **申請の単位**：会社単位で受け付け、評価・集計は事業単位とする案でよいか
7. **DX調査の非公開回答の読み込み**：本人の同意を取る形でよいか、経産省に確認
8. **ユーザーテスト**：モック v4で、事業部とDX推進部の人が「自分の施策がどこにつながるか」を読み取れるか確かめる
